# Backend SonarQube Coverage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with verification checkpoints.

**Goal:** Generate backend Jest LCOV coverage and import it into the local SonarQube analysis.

**Architecture:** Reuse the existing backend Jest `test:cov` script through a small wrapper that writes Jest's native `apps/backend/coverage/lcov.info` and a repository-rooted `apps/backend/coverage/sonar-lcov.info`. Add one SonarQube analysis property pointing to the normalized report; the existing read-only `apps` volume mount makes the file available inside the scanner container.

**Tech Stack:** pnpm 8, Jest 29, ts-jest, TypeScript, SonarScanner CLI, SonarQube Community Build.

## Global Constraints

- Use pnpm only.
- Do not create or modify `*.spec.ts` or `*.test.ts` files.
- Do not run build or lint commands.
- Do not launch the already-running backend or frontend applications.
- Run `pnpm typecheck` after configuration changes and inspect the applicable runtime logs.
- Do not use Git commands.
- Do not change Quality Gate thresholds or exclude source files to force a pass.

### Task 1: Add the LCOV import configuration

**Files:**
- Modify: `sonar-project.properties`
- Modify: `apps/backend/package.json`
- Create: `apps/backend/scripts/test-coverage.cjs`

**Interfaces:**
- Consumes: The normalized report generated by the backend coverage wrapper.
- Produces: SonarScanner configuration for `apps/backend/coverage/sonar-lcov.info`.

- [ ] **Step 1: Replace the commented placeholder with the active property**

```properties
sonar.javascript.lcov.reportPaths=apps/backend/coverage/sonar-lcov.info
```

Keep `**/coverage/**` in `sonar.exclusions` so generated report files are not treated as source files.

- [ ] **Step 2: Verify only the intended Sonar property changed**

Run:

```powershell
Select-String -Path sonar-project.properties -Pattern 'sonar.javascript.lcov.reportPaths|coverage'
```

Expected: the active LCOV property points to `apps/backend/coverage/lcov.info`, and the coverage exclusion remains present.


Expected: the existing Jest suite completes and Jest reports coverage output. The wrapper writes the normalized SonarQube report even if Jest exits non-zero; do not add or edit tests if a test fails.

- [ ] **Step 2: Verify the LCOV report**

```powershell

```

Expected: the file exists, has a positive length, and contains `SF:apps/backend/src/...` source-file records.
